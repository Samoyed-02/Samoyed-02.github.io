## 2. front matter `tag` → `tags` 수정

커밋 `deee3c2`

### 문제

Hugo의 taxonomy 키는 `tags`인데 일부 페이지가 `tag :`로 작성되어 있었다.
Hugo는 이를 알 수 없는 일반 파라미터로 취급하므로, 해당 페이지의 태그가 태그 목록·태그 클라우드·관련 글 추천 어디에도 반영되지 않았다.

### 수정 대상

| 구분 | 파일 |
| --- | --- |
| projects | `dopamin-treasure`, `enlist-korea`, `likelion-cms`, `pickstranger` |
| posts | `retrospective/guard-up-ideation` |
| (참고) | `projects/morrow`: 커밋되지 않은 로컬 변경이 `tags:` → `tag :` 한 줄뿐이었고, 되돌리자 HEAD와 동일해져 커밋 대상 없음 |

수정 후 `content/` 전체에서 `tag :` 키 사용 0건.

### 검증

- 로컬 빌드에서 새 태그 디렉터리 생성 확인: `백엔드리더`, `군입영지원`, `postgis`, `멋쟁이사자처럼`, `리버스프록시`, `아이디어기획`
- 배포 후 실제 사이트: `/tags/백엔드리더/`, `/tags/군입영지원/`, `/tags/리버스프록시/`, `/tags/아이디어기획/` 모두 200

## 3. Guard-Up RAG 파이프라인 구조도 추가

커밋 `88a3b1c` · 파일 `content/projects/guard-up/index.md`, `content/projects/guard-up/rag_pipeline.png`

### 이미지 위치 이동

| 구분 | 경로 |
| --- | --- |
| 저장되어 있던 위치 | `resources/_gen/images/projects/Guard-Up/rag_pipeline.png` |
| 옮긴 위치 | `content/projects/guard-up/rag_pipeline.png` (page bundle) |

`resources/_gen/`은 Hugo가 이미지 처리·SCSS 결과를 저장하는 빌드 캐시 디렉터리다.
`.gitignore`로 제외되어 있어 커밋·배포되지 않고, `hugo --gc` 실행 시 정리될 수도 있다.
글에 쓰는 이미지는 해당 글의 `index.md`와 같은 폴더(page bundle)에 두어야 한다.

### 본문 변경

"RAG 파이프라인 개발 🔒" 섹션 제목 아래에 흐름 설명 한 문장과 구조도를 삽입했다.

```markdown
법률 데이터 46건은 서버 시작 시 1회만 KURE-v1로 임베딩해 ChromaDB에 저장하고, 분석 요청마다
마스킹된 계약서 텍스트를 같은 모델로 임베딩해 유사도 Top-5 조항을 조회한 뒤 GPT-4o 리스크 분석의
프롬프트 컨텍스트로 전달합니다.

![RAG 파이프라인](rag_pipeline.png)
```

- 구조도 내용: 인덱싱(서버 시작 시 1회) 법률 데이터 JSON 46건 → 문서 변환 → KURE-v1 문서 임베딩 → ChromaDB 저장 / 검색·분석(요청마다) 마스킹 텍스트 → KURE-v1 쿼리 임베딩 → 유사도 Top-5 조회 → 관련 조항 → GPT-4o 리스크 분석
- "Top-5"는 백엔드 `search_relevant_clauses(n_results=5)` 기본값과 일치
